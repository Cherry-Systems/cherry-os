Cherry Store

by Cherry Systems

Apps for Cherry OS and other Debian-based Linux, published by anyone. Install with the Cherry Store app or cherry install NAME. Every package is an ordinary Debian package, signed by its publisher and virus-scanned; warnings are shown, nothing is judged. They're all kept in Cherry-Systems/cherry-store. The Cherry Store app and Cherry Cloud are part of the Cherry OS source.

Get the Cherry Store app

For Ubuntu, Linux Mint, Debian, Pop!_OS, Zorin OS, elementary OS and other Debian-based Linux.

Download for Linux (.deb)

Open the downloaded file to install it with your software app, then find Cherry Store among your apps. It keeps itself up to date. Or install it from a terminal:

wget -O /tmp/cherry-store.deb https://cherry-cloud.isaiahcannings.workers.dev/download/cherry-store.deb
sudo apt install /tmp/cherry-store.deb

Needs Ubuntu 22.04, Linux Mint 21, Debian 12 or newer (64-bit PC or ARM). On Ubuntu 22.04, use the terminal commands. Cherry OS already includes it.

Publish your app

On Cherry OS, or with the Cherry Store app installed: cherry init and cherry build in your project, then cherry publish --github (with your GitHub account) or cherry signup YOURNAME and cherry publish --cherry. No review queue, no approval.
